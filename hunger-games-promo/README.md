# Промо-ролик «Голодные игры» · Снежинск

Атмосферный снежный трейлер турнира голодных игр в Minecraft Java на 20 игроков.
Ролик собирается из кода на [Remotion](https://www.remotion.dev). Нарезку и
упаковку делает ffmpeg. Монтаж сам подстраивается под биты трека.

**На выходе** (папка `out/`):

| Файл | Формат | Куда |
|---|---|---|
| `promo-9x16-1080x1920.mp4` | 1080×1920, H.264, 30 fps, 40 с | Telegram, VK Клипы, TikTok, Reels |
| `promo-16x9-1920x1080.mp4` | 1920×1080, H.264, 30 fps, 40 с | YouTube, VK |
| `cover-1080x1920.jpg` | обложка 9:16 | превью клипов |
| `cover-1280x720.jpg` | обложка 16:9 | превью YouTube и VK |

## Структура ролика

| Время | Что происходит |
|---|---|
| 0–3 с | Хук: самый эффектный удар в замедлении, вспышка и тряска на ударе |
| 3–25 с | Нарастание: склейки по битам, всё короче к концу, вспышки на сильных долях |
| 25–30 с | Музыка обрывается. Ветер, шаги, один кадр победителя, метель в белое |
| 30–40 с | Финальная карточка: единственный текст в ролике |

Поверх всех кадров идут падающий снег, иней по краям и холодная цветокоррекция.
Метель усиливается на дуэли и на победителе.

## Установка

Нужен [Node.js](https://nodejs.org) версии 20.11 или новее, лучше 22.
Отдельно ставить ffmpeg не нужно: если его нет в системе, берётся тот, что
идёт вместе с Remotion.

```bash
cd hunger-games-promo
npm install
npm run demo-audio   # своя музыка и звуки, если своих файлов пока нет
npm run prep
npm run render:all
```

Без записей геймплея ролик тоже соберётся: вместо кадров будут тёмные
снежные заглушки. Так можно сразу проверить музыку, ритм и карточку.

При первом рендере Remotion сам скачает Chrome Headless Shell, около 100 МБ.

## Папки

```
hunger-games-promo/
├── promo.config.ts   ← ВСЕ настройки: текст, дата, цена, музыка, кадры
├── shot-list.md      ← что снять в ReplayMod
├── footage/          ← ваши записи из ReplayMod (.mp4)
├── audio/            ← музыкальный трек
├── sfx/              ← ветер, шаги, удар меча, колокол
├── out/              ← готовые ролики и обложки
├── public/           ← сюда npm run prep кладёт нарезку (не трогать)
├── scripts/          ← prep, bpm, timeline, render
└── src/              ← сам ролик на React
```

Записи, музыка и звуки в git не попадают, папки остаются пустыми.

## Как добавить кадры

1. Снимите кадры по `shot-list.md` и отрендерите их из ReplayMod в MP4, лучше в 60 fps.
2. Положите файлы в `footage/`.
3. В `promo.config.ts → shots` для каждого кадра укажите файл и кусок:

   ```ts
   { id: 4, name: 'Бой на мечах', source: '04-sword.mp4', start: '0:12.5', duration: 10 },
   ```

   - `start` — с какой секунды исходника резать: `12.5` или `"0:12.5"`.
   - `duration` — сколько секунд вырезать. Берите с запасом.
   - `rate` — замедление в ролике: `0.5` — вдвое медленнее.
   - `focusX` — куда сдвинуть кадр в вертикальной версии: `0` левый край,
     `0.5` центр, `1` правый край.
   - `blizzard` — сила метели поверх кадра: `1` обычная, `2.5` сильная.

4. Запустите подготовку:

   ```bash
   npm run prep
   ```

   Команда вырежет куски в `public/clips/`, подключит музыку и звуки,
   определит темп и покажет монтажный лист. Если кадр не снят, в ролике будет
   тёмная снежная заглушка. Подпись на ней видна только в Studio.

5. Посмотрите, что получилось:

   ```bash
   npm run studio
   ```

   Откроется браузер с превью. Слева выбирайте `Promo-Vertical`,
   `Promo-Horizontal` или обложки.

Хук берёт кадр 4 с секунды `hook.from`. Удар должен прийтись на
`hook.impactSec` секунду ролика, поэтому сдвигайте `hook.from`, пока удар не
совпадёт со вспышкой. Кадр победителя задаётся в `pause`, фон обложек — в `cover`.

## Музыка и синхронизация с битами

**Быстрый старт без своих файлов:**

```bash
npm run demo-audio
```

Команда синтезирует собственный трейлерный трек на 120 BPM и все четыре звука:
ветер, шаги, удар меча, колокол. Это ваш собственный звук, авторских прав
третьих лиц на нём нет. Файлы ложатся в `audio/` и `sfx/` под теми же именами,
что в конфиге. Уже лежащие там файлы команда не трогает, `--force` их перезапишет.
Чтобы заменить демо-звук на настоящий, положите свой файл с тем же именем.

**Свой трек:**

1. Положите трек без авторских прав в `audio/`, например `audio/track.mp3`.
2. Впишите имя в `music.file`. Если в треке длинное вступление, задайте в
   `music.startSec`, с какой секунды начинать.
3. `npm run prep` или `npm run bpm` сам определит темп и первую сильную долю.
   Результат запишется в `src/generated/beats.json`.

**Если вспышки попадают мимо битов**, задайте темп вручную:

```ts
bpm: 128,            // темп трека
firstBeatSec: 0.42,  // секунда первой сильной доли в файле
```

Проверить любой трек без записи результата:

```bash
npm run bpm -- audio/другой-трек.mp3
```

**Ритм монтажа** задаётся в `build`:

- `order` — порядок кадров. Повтор кадра берёт его следующий кусок.
- `firstCutSec` и `lastCutSec` — длина склеек в начале и в конце нарастания.
- `acceleration` — как резко ускоряется монтаж.
- `beatsPattern` — ручной ритм в долях, например `[4, 4, 4, 4, 2, 2, 2, 2, 1, 1, 1, 1]`.

Все склейки ложатся на доли. Длинные куски начинаются с сильной доли такта,
и на них идёт вспышка.

Посмотреть монтажный лист и сколько секунд каждой записи нужно:

```bash
npm run timeline
```

## Как поменять текст, дату и цену

Всё в начале `promo.config.ts`, раздел `card`:

```ts
card: {
  title: 'ГОЛОДНЫЕ ИГРЫ',
  subtitle: 'СНЕЖИНСК',
  tagline: '20 игроков. 1 выживший.',
  date: '15 ноября · 18:00',
  fee: 'Взнос 300 руб.',
  prize: 'Призовой фонд 5 000 руб.',
  link: 'https://t.me/your_channel',   // из этого адреса строится QR-код
  linkLabel: '',                       // пусто — показать сам адрес
  callToAction: 'Регистрация',
  showQr: true,
  disclaimer: 'Неофициальный сервер. Не является продуктом Mojang/Microsoft.',
},
```

Пустая строка убирает строку с карточки. Длинное название само уменьшается
по ширине. Знак ₽ в шрифте Montserrat отсутствует и будет нарисован системным
шрифтом, поэтому надёжнее писать «руб.».

**Пересобрать с новой датой:** поменяйте `date` и запустите `npm run render:all`.
Нарезку при этом заново делать не нужно.

## Рендер

```bash
npm run render:all          # оба ролика и обе обложки
npm run render:vertical     # только 9:16
npm run render:horizontal   # только 16:9
npm run render:covers       # только обложки
npm run build               # prep + render:all одной командой
```

Ролик рендерится в H.264 с AAC 320 кбит/с и цветом BT.709. Затем ffmpeg
переупаковывает файл с `+faststart`, чтобы видео сразу начинало играть в
соцсетях.

- **60 fps:** `video.fps: 60`. Рендер станет вдвое дольше.
- **Качество:** `video.crf`. Меньше значение — лучше картинка и тяжелее файл.
  `18` почти без потерь.
- **Длина ролика:** `video.durationSec`, `structure.*`.
- Любые флаги Remotion передаются после `--`, например:
  `npm run render:vertical -- --concurrency=4`.

Рендер 40 секунд занимает несколько минут, в зависимости от процессора.

## Звуки

`sfx` в конфиге: имя файла в `sfx/` и громкость. Если файла нет, звук просто
пропускается.

| Ключ | Когда звучит |
|---|---|
| `wind` | Весь ролик по кругу, громче в паузе (`pauseVolume`) |
| `footsteps` | Пауза с победителем |
| `swordHit` | Удар в хуке и каждая склейка на бой мечами |
| `bell` | Старт (кадр 3) и появление карточки |

## Стиль

Раздел `look`: цвета (белый, ледяной голубой, тёмно-синий), сила
цветокоррекции `gradeStrength`, количество снежинок `snowflakes`, иней `frost`.
`0` выключает эффект.

## Частые проблемы

- **Кадр показывает заглушку.** Проверьте имя файла в `source` и что
  `npm run prep` написал «готово» для этого кадра.
- **Кусок замедлен сам.** Записи не хватило на длину куска.
  `npm run timeline` покажет предупреждение. Увеличьте `duration`.
- **Студия не видит изменений после prep.** Перезапустите `npm run studio`.
- **Chrome не скачивается** без доступа к remotion.media. Укажите свой браузер:
  `npm run render:all -- --browser-executable="путь/к/chrome"`.

## Правовое

В ролике нет чужих роликов, логотипов Minecraft и Mojang. На карточке есть
дисклеймер о неофициальном сервере. Используйте только свою запись геймплея
и музыку со свободной лицензией.
