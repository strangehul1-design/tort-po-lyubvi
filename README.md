# Мелия — лендинг кондитерской по свадебным тортам

Демонстрационный одностраничник без сборки и зависимостей. Открывается двойным
кликом по `index.html` или заливается на любой статический хостинг.

| Файл | Что внутри |
|---|---|
| `index.html` | Вся страница: восемь блоков и линейная графика вместо фото |
| `styles.css` | Оформление страницы |
| `forms.css` | Оформление форм |
| `forms.js` | Движок форм: заказ торта и запись на дегустацию |
| `app.js` | Шапка, слоты под фото, появление блоков |

## Запуск

```bash
npx -y serve -l 4323 melia
```

## Структура

1. **Первый экран** — заголовок, две кнопки, фото во всю ширину
2. **Работы** — шесть тортов со свадеб: фото, название, ярусы и площадка
3. **Как проходит заказ** — четыре шага: эскиз, дегустация, выпечка, доставка
4. **Доставка** — почему возим лично, от чего зависит стоимость, две иллюстрации: в дороге и сборка на месте
5. **Заказать торт** — восемь полей
6. **Дегустация** — описание формата и короткая форма записи
7. **Свадьбы** — галерея и три отзыва
8. **Подвал** — контакты, соцсети, зона доставки

## Откуда стиль

Ориентир — [weddingolivia.ru](https://weddingolivia.ru) и
[samara.unirenter.ru](https://samara.unirenter.ru). У «Оливии» взят типографический
приём: изящный serif **Forum** в заголовках, широкие разрядки в надписях капсом,
белая база и тёплый разговор от первого лица. У Unirenter — принцип «фото решают»:
крупная плитка снимков и тихая типографика без украшательств.

Палитра — по вашему брифу: айвори `#FCFAF6`, пудра `#E7CFC9`, шампань `#EADDC6`,
мягкий графит `#3A3532`. Отступы между блоками `clamp(76px, 12vw, 180px)`.

## Фотографии

Фото — главный акцент, но в демо их нет. Пока файла нет, на месте снимка стоит
линейный рисунок, и страница выглядит целой, а не сломанной.

Чтобы поставить настоящие фото:

1. Положите файлы в `images/` с именами из атрибутов `data-photo`:
   `hero.jpg`, `work-1.jpg` … `work-6.jpg`, `delivery-van.jpg`,
   `delivery-setup.jpg`, `wedding-1.jpg` … `wedding-6.jpg`
2. В `index.html` поставьте `<html lang="ru" data-photos="on">`

Слоты подхватят их сами. Если какого-то файла не окажется, на его месте останется
рисунок — остальные покажутся нормально.

Пропорции: первый экран 16:8, работы 4:5, доставка 4:3, галерея — плитка,
кадрируется по центру.

## Формы

Обе собраны одним движком по описанию полей — блок `FORMS` в начале `forms.js`.
Чтобы добавить или убрать поле, правится только это описание.

**Заказать торт**, восемь полей: дата свадьбы, место проведения, количество
гостей, желаемый декор, начинка, презентация и нарезка, контактные данные,
дополнительная информация.

**Записаться на дегустацию**, три поля: желаемая дата, количество человек,
контактные данные.

Что они делают сами:

- **Декор** — переключатель: «Пришлю референс» открывает загрузку фото, «Обсудим индивидуально» её прячет и очищает уже приложенное
- **Начинка** — в списке есть «Хочу заказать дегустацию и выбрать на месте»
- **Контакты** — способ связи и удобное время попадают в заявку одной строкой: `WhatsApp: +7 917 000-11-22 (вечером)`
- Считают заполненные поля — «6 / 8» в шапке формы
- Ловят прошедшую дату
- Принимают до четырёх фото перетаскиванием, отсеивают не-картинки и файлы тяжелее 8 МБ
- Показывают текст заявки целиком, до отправки
- Добавляют ссылку «Ответить» — по ней вы сразу попадаете в диалог с клиентом

### Куда приходят заявки

Настраивается в `forms.js`, блок `CONFIG.transport`.

**Telegram-бот** — заявка уходит сразу, вместе с фото:

```js
transport: {
  telegram: { token: '123456:AA...', chatId: '987654321' },
  webhook:  { url: '' }
}
```

`token` — у [@BotFather](https://t.me/BotFather), `chatId` — у [@userinfobot](https://t.me/userinfobot).
Один раз напишите боту `/start`. Токен виден в исходнике страницы: для бота,
который только принимает заявки, это терпимо, иначе — webhook.

**Webhook** — `POST multipart` на ваш адрес, токен остаётся на сервере.

**Ничего не заполнено** — режим демо: форма показывает экран передачи, клиент
сохраняет фото под понятными именами, копирует текст и переходит в диалог.

Само, без действий клиента, отправляется только Telegram или webhook. ВК и
WhatsApp из браузера так не умеют, а приложить файл за клиента невозможно
в принципе — поэтому фото сохраняются на устройство и прикладываются скрепкой.

## Что заменить перед публикацией

Всё содержимое вымышленное — это демонстрация, а не реальная кондитерская.

| Где | Что |
|---|---|
| Везде | Название «Мелия» |
| Подвал | Телефон `+7 900 000-00-00`, почта `hello@melia.example`, соцсети |
| Блок «Работы» | Шесть подписей: названия, ярусы, площадки |
| Блок «Доставка» | Зона доставки, радиус, порядок расчёта стоимости |
| Блок «Дегустация» | Формат, длительность, число начинок, стоимость |
| Блок «Свадьбы» | Три отзыва — сейчас помечены как демо. Публиковать только с согласия пар |
| `forms.js`, `FILLINGS` | Список начинок |
| `forms.js`, `CONFIG` | Телефон для WhatsApp, адрес группы ВК, время ответа |

## Доступность

Адаптив от 375 px, поддержка `prefers-reduced-motion`, видимый фокус с клавиатуры,
поля связаны с подписями, ошибки объявляются через `role="alert"`, первый экран
не прячется анимацией и виден сразу.
