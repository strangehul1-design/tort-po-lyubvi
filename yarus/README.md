# Ярус — лендинг кондитерской по свадебным тортам

Демонстрационный одностраничник без сборки и зависимостей. Открывается двойным
кликом по `index.html` или заливается на любой статический хостинг.

| Файл | Что внутри |
|---|---|
| `index.html` | Вся страница: семь блоков и линейная графика вместо фото |
| `styles.css` | Оформление страницы |
| `forms.css` | Оформление форм |
| `forms.js` | Движок форм: заявка на торт и запись на дегустацию |
| `app.js` | Шапка, фильтры каталога, слоты под фото, появление блоков |

## Запуск

```bash
npx -y serve -l 4322 yarus
```

## Структура страницы

1. **Первый экран** — крупный слот под фото, заголовок, «Смотреть каталог» и «Записаться на дегустацию»
2. **Каталог** — восемь композиций: фото, название, ярусы, вес, гости, цена. Фильтр по стилю и сортировка по цене и весу
3. **По эскизу** — четыре шага с иконками: референс → детали → эскиз → доставка
4. **Дегустация** — где, сколько длится, что пробуют, сколько стоит + форма записи
5. **Заявка** — семь полей, основной конверсионный блок
6. **Свадьбы** — галерея из шести слотов и три отзыва
7. **Подвал** — контакты, соцсети, часы работы

## Фотографии

Фото — главный герой страницы, но в демо их нет. Пока файла нет, на месте снимка
стоит линейный рисунок торта, и страница выглядит целой, а не сломанной.

Чтобы поставить настоящие фото:

1. Положите файлы в `images/` с именами из атрибутов `data-photo`:
   `hero.jpg`, `cake-klassika.jpg`, `cake-yagodny-sad.jpg`, `cake-pudra.jpg`,
   `cake-naked.jpg`, `cake-bely-barhat.jpg`, `cake-shampan.jpg`,
   `cake-florentina.jpg`, `cake-zimny-sad.jpg`, `wedding-1.jpg` … `wedding-6.jpg`
2. В `index.html` поставьте `<html lang="ru" data-photos="on">`

Слоты подхватят снимки сами. Если какого-то файла не окажется, на его месте
останется рисунок — остальные покажутся нормально.

Пропорции: первый экран 4:5, карточки каталога 3:4, галерея — плитка,
кадрируется по центру.

## Формы

Обе формы собраны одним движком по описанию полей — блок `FORMS` в начале
`forms.js`. Чтобы добавить или убрать поле, правится только это описание.

**Заявка на торт**, семь полей: тип торта (из каталога или по эскизу), начинка,
вес и гости, дата свадьбы, пожелания по дизайну, референс-фото, контакт.

**Запись на дегустацию**, четыре поля: удобная дата, сколько человек придёт,
дата свадьбы, контакт.

Что они делают сами:

- Кнопка «Выбрать» в каталоге подставляет композицию в заявку и отмечает «Из каталога»
- Считают заполненные поля — «5 / 7» в шапке формы
- Предупреждают, если до свадьбы меньше трёх недель, и ловят прошедшую дату
- Принимают до четырёх фото перетаскиванием, показывают превью, отсеивают не-картинки и файлы тяжелее 8 МБ
- Меняют подсказку контакта под выбранный канал: телефон, `@ник`, `vk.com/страница`
- Показывают текст заявки целиком, до отправки
- Добавляют в заявку ссылку «Ответить» — по ней вы сразу попадаете в диалог с клиентом

### Куда приходят заявки

Настраивается в `forms.js`, блок `CONFIG.transport`.

**Telegram-бот** — заявка уходит сразу, вместе с фото:

```js
transport: {
  telegram: { token: '123456:AA...', chatId: '987654321' },
  webhook:  { url: '' }
}
```

`token` — у [@BotFather](https://t.me/BotFather), `chatId` — у [@userinfobot](https://t.me/userinfobot).
Один раз напишите боту `/start`. Токен виден в исходнике страницы: для бота,
который только принимает заявки, это терпимо, иначе — webhook.

**Webhook** — `POST multipart` на ваш адрес, токен остаётся на сервере. Придут
поля формы, готовый `text`, номер заявки и файлы `ref1…ref4`.

**Ничего не заполнено** — режим демо. Форма показывает экран передачи: клиент
сохраняет фото под понятными именами, копирует текст и переходит в диалог.
Копирование и переход происходят одним нажатием, иначе браузер блокирует вкладку.

Само, без действий клиента, отправляется только Telegram или webhook. ВК и
WhatsApp из браузера так не умеют: ВК не принимает ни текст, ни вложения по
ссылке, у WhatsApp нет браузерного API. Прикрепить фото за клиента невозможно —
поэтому файлы сохраняются на устройство, а в диалоге прикладываются скрепкой.

## Что заменить перед публикацией

Всё содержимое вымышленное — это демонстрация, а не реальная кондитерская.

| Где | Что |
|---|---|
| Везде | Название «Ярус» |
| Подвал | Телефон `+7 900 000-00-00`, почта `hello@yarus.example`, ссылки на соцсети |
| Каталог | Восемь композиций: названия, ярусы, вес, цены |
| `forms.js`, `FILLINGS` | Список начинок |
| Блок «Дегустация» | Адрес, длительность, число начинок, стоимость |
| Блок «Свадьбы» | Три отзыва — сейчас помечены как демо |
| `forms.js`, `CONFIG` | Телефон для WhatsApp, адрес группы ВК, время ответа |

## Оформление

- **Палитра.** Тёплый белый `#FBF9F6`, пудровая роза `#E3C9C6`, шампань `#EADFC9`, графит `#2A2724`
- **Шрифты.** Cormorant Garamond — заголовки, Manrope — текст
- **Воздух.** Отступы между блоками `clamp(72px, 11vw, 168px)`
- Адаптив от 375 px, поддержка `prefers-reduced-motion`, видимый фокус с клавиатуры,
  поля связаны с подписями, ошибки объявляются через `role="alert"`
