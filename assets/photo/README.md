# Фотографии работ

Сюда кладём исходные снимки для галереи на главной.

## Как добавить фото

1. Скопируйте файлы в эту папку (`assets/photo/`). Имена любые —
   порядок в галерее берётся по имени файла, поэтому удобно нумеровать.
   Понимает `.jpg`, `.jpeg`, `.png`, `.bmp`.

2. Запустите из корня проекта:

       powershell -ExecutionPolicy Bypass -File tools/gallery-manifest.ps1

Скрипт развернёт кадры, снятые боком (по EXIF), сложит в `web/` две
облегчённые копии каждого снимка — на 800px для плиток и на 1600px для
просмотра во весь экран — и перепишет `assets/gallery.js`.

## Почему так

Исходники со свадеб весят по мегабайту и больше. Если отдавать их как
есть, посетитель с телефона выкачает десятки мегабайт ради галереи,
которую пролистает за минуту. Копии на 800px весят около 100 КБ, и
браузер сам решает по `srcset`, какую версию скачать.

Размеры каждой копии записываются в манифест и попадают в атрибуты
`width`/`height`. Благодаря этому браузер знает пропорции заранее и
плитки не прыгают, пока снимки грузятся.

## Что попадает в репозиторий

Только `web/` и этот файл. Оригиналы перечислены в `.gitignore` —
они остаются на вашем диске. Если понадобится пересобрать галерею на
другой машине, скопируйте туда исходники и запустите скрипт заново.
