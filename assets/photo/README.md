# Фотографии работ

Сюда кладём снимки готовых тортов для галереи на главной.

**Как добавить фото:**
1. Скопируйте файлы в эту папку (`assets/photo/`).
2. Имена — любые, но лучше по порядку: `01.jpg`, `02.jpg`, … Порядок
   в галерее берётся из имени файла по алфавиту.
3. Запустите из корня проекта:

       powershell -ExecutionPolicy Bypass -File tools/gallery-manifest.ps1

   Скрипт прочитает реальные размеры каждого снимка и перезапишет
   `assets/gallery.js`. Размеры нужны, чтобы браузер заранее знал
   пропорции и картинки не «прыгали» при загрузке.

Поддерживаются `.jpg`, `.jpeg`, `.png`, `.webp`.

Пока файлов нет, галерея показывает аккуратные заглушки — вёрстка
не ломается.
