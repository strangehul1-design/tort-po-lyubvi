# Демо-сайт: Асия Зубаирова — торты на заказ, Самара

Статичный сайт по материалам сообщества [vk.ru/asiyatort](https://vk.ru/asiyatort).
Без сборки и зависимостей.

| Файл | Что внутри |
|---|---|
| `index.html` | Сайт целиком, форма заявки — в секции «Контакты» |
| `form.html` | Только форма, отдельной страницей — для ссылки в шапке ВК или для iframe |
| `order-form.js` | Виджет формы: разметка, проверки, отправка. Все настройки — в `CONFIG` наверху |
| `app.js` | Каталог, фильтры, меню |
| `styles.css` | Оформление сайта и формы |

## Запуск

```bash
npx -y serve -l 4321 asiya-tort
```

## Форма заявки

Девять полей: тип изделия, повод, начинка, размер, дата, пожелания по дизайну,
референс-фото, бюджет, контакт. Плюс кнопка «Отправить заявку» и экран
«Заявка получена».

Что она делает сама:
- **Размер подстраивается под изделие.** Торт — 1–2 / 2–3 / 3–5 кг, капкейки — 6 / 12 / 24 шт., десерты — 10 / 20 / 50 шт. Везде есть «свой вариант».
- **Считает гостей** из веса торта (180 г на человека) и подставляет в заявку: «2–3 кг (≈ 11–17 гостей)».
- **Предупреждает о срочности.** Если до даты меньше трёх дней — «Срочный заказ, подтвержу в ответе». Прошедшую дату подсвечивает.
- **Считает заполненные поля** — «5 из 9» в шапке формы.
- **Принимает до 3 фото** перетаскиванием или выбором, показывает превью, отсеивает не-картинки и файлы тяжелее 8 МБ.
- **Меняет подсказку контакта** под выбранный канал: телефон, `@ник`, `vk.com/страница`.
- **Проверяет обязательное** — тип изделия, дата, контакт — и подсвечивает нужный шаг.
- Из каталога кнопка «Заказать» подставляет позицию, тип изделия и повод: «Свадебный ярусный» → торт + свадьба, «Моти» → десерты.

Обязательны только три поля, остальное можно пропустить — заявка всё равно уйдёт.

### Куда приходит заявка

Настраивается в `order-form.js`, блок `CONFIG.transport`. Виджет сам выбирает режим.

**1. Telegram — заявка уходит боту сразу, вместе с фото.**

```js
transport: {
  telegram: { token: '123456:AA...', chatId: '987654321' },
  webhook:  { url: '' }
}
```

- `token` — у [@BotFather](https://t.me/BotFather), команда `/newbot`.
- `chatId` — свой id узнать у [@userinfobot](https://t.me/userinfobot). Для общего чата с помощницей — добавить бота в группу и взять id группы (начинается с `-100`).
- Перед первой заявкой нужно один раз написать боту `/start`, иначе Telegram не примет сообщение.

Оговорка: токен лежит в коде страницы, его видно любому, кто откроет исходник.
Для личного бота, который только принимает заявки, это терпимо — максимум,
что сделает злоумышленник, это пришлёт мусор в тот же чат. Если это не устраивает —
режим 2.

**2. Webhook — токен остаётся на сервере.**

```js
webhook: { url: 'https://ваш-адрес/order' }
```

Форма шлёт `multipart/form-data`: поля `kind`, `reason`, `filling`, `size`, `date`,
`design`, `budget`, `name`, `channel`, `contact`, `catalogItem`, готовый `text`
и файлы `ref1`…`ref3`. Дальше ваш обработчик (Cloudflare Worker, Vercel Function,
простой PHP) пересылает это куда угодно — в Telegram, на почту, в CRM.

**3. Ничего не заполнено — режим по умолчанию.** Форма собирает текст, копирует
его в буфер обмена и открывает мессенджер, выбранный клиентом: WhatsApp с готовым
текстом, диалог группы ВК или окно пересылки Telegram. Человек вставляет и отправляет.
Работает сразу, без настройки, но требует одного действия от клиента.

### Что уходит само, а что нет

| Куда | Само, без участия клиента | Что нужно |
|---|---|---|
| Telegram-бот | **да**, вместе с фото | токен в `CONFIG` |
| Ваш webhook | **да**, вместе с фото | свой обработчик |
| WhatsApp | нет | откроется чат с готовым текстом, клиент жмёт «Отправить» |
| ВКонтакте | нет | экран передачи: сохранить фото, скопировать текст, перейти в диалог |
| Telegram без бота | нет | то же самое, только диалог Telegram |

Из браузера напрямую можно писать только в Telegram: его Bot API открыт для
запросов со страницы. У WhatsApp такого API нет вовсе (только серверный Cloud API
с бизнес-аккаунтом Meta), а ВК не отвечает на запросы из браузера. Всё остальное —
это ссылка, которая открывает нужный диалог с подставленным текстом.

### Как выглядит заявка в боте

Сообщение приходит карточкой, с кнопкой «связаться» под ней:

```
🎂 Заявка № 2008-1810

Изделие: Торт — Свадебный ярусный
Повод: Свадьба
Начинка: Красный бархат
Размер: 3—5 кг (≈ 17—28 гостей)
Дата: 10.09.2026 (через 21 день)
Дизайн: Белый, минимализм
Референсы: 2 фото
Бюджет: 6 000 — 10 000 ₽

Арсений
WhatsApp: +7 917 000-11-22

[ 💬 Написать в WhatsApp ]
```

- **Номер заявки** — день-месяц и время. По нему удобно искать переписку и подписаны фото: «Референс 1 к заявке № 2008-1810».
- **Кнопка под сообщением** ведёт в диалог с клиентом в том канале, который он выбрал: WhatsApp, Telegram или страница ВК. Одно нажатие — и вы уже пишете ответ.
- **Телефон** кнопкой не оформляется — Telegram разрешает в кнопках только веб-ссылки. Номер остаётся в тексте, и Telegram сам делает его нажимаемым: тап — звонок.
- **Фото** приходят следом отдельными сообщениями, каждое подписано номером заявки.
- Всё, что человек написал сам (пожелания по дизайну, повод), экранируется — угловые скобки и амперсанды не ломают форматирование.

### Если бот не ответил

Нет сети, неверный токен, боту не написали `/start` — на экране появится причина
и кнопка «Открыть WhatsApp с этой заявкой». Заполненная заявка не пропадает,
клиент доводит её вторым путём.

### Экран передачи: ВКонтакте и Telegram

Нажатие «Отправить заявку» ничего не открывает само — вместо этого показывается
экран передачи, и клиент проходит его сам:

1. **Фото** — миниатюры и кнопка «Сохранить фото на устройство». Файлы скачиваются
   под понятными именами: `zayavka-2008-2136-foto-1.png`. В диалоге их прикладывают
   скрепкой.
2. **Текст** — заявка показана целиком, кнопка «Скопировать текст и открыть
   ВКонтакте». Копирование и переход происходят в одном нажатии, поэтому браузер
   не блокирует вкладку и не отказывает в доступе к буферу обмена.

Есть кнопка «Вернуться к форме», если клиент передумал, и «Скопировать текст ещё
раз» на финальном экране — если буфер обмена успели перезаписать.

Почему так, а не автоматически: ВК не позволяет странице ни подставить текст в
сообщение, ни приложить файл — ни ссылкой, ни через API из браузера. Прикрепить
фото за клиента невозможно в принципе; сохранение файлов с понятными именами —
максимум, что помогает. Если нужна полная автоматика с фото — только Telegram-бот
или webhook.

### Маршруты по каналам

`CONFIG.routes` — куда уходит заявка в зависимости от того, какой канал выбрал клиент:

```js
routes: {
  'Телефон':   'vk',        // выбрал телефон → заявка идёт во ВКонтакте
  'Telegram':  'telegram',
  'WhatsApp':  'whatsapp',
  'ВКонтакте': 'vk'
},
alwaysToBot: true
```

`alwaysToBot: true` (по умолчанию) — если Telegram-бот настроен, **все** заявки
уходят ему автоматически, какой бы канал клиент ни выбрал. Это рекомендуемый режим:
все заявки в одном чате, ничего не теряется, а выбранный клиентом канал становится
строкой в заявке и готовой ссылкой для ответа:

```
Связь: Арсений, Телефон: +7 917 000-11-22
Ответить: tel:+79170001122
```

Для Telegram там будет `https://t.me/ник`, для WhatsApp — `https://wa.me/номер`,
для ВК — ссылка на страницу. Одно нажатие — и вы в нужном диалоге.

`alwaysToBot: false` — заявка идёт по `routes`. Тогда часть заявок будет уходить
автоматически (Telegram), а часть — открывать диалог, где клиенту нужно нажать
«отправить». Часть клиентов на этом шаге отваливается, поэтому режим «всё боту»
надёжнее.

### Про ВКонтакте

Автоматически принять заявку в личку группы ВК со статичной страницы нельзя:
API ВК не отвечает на запросы из браузера, а групповой токен в коде — это доступ
к сообществу, а не к одному чату. Рабочие варианты: webhook (режим 2) с серверным
ботом ВК, либо режим 3 — открыть диалог с готовым текстом. Поэтому автоотправка
сделана на Telegram.

## Что заменить перед публикацией

| Где | Что | Почему |
|---|---|---|
| `order-form.js`, `CONFIG.fillings` | Список начинок | **Придуман.** На странице ВК ассортимент начинок не опубликован — нужен настоящий список |
| `order-form.js`, `CONFIG.budgets` | Диапазоны бюджета | Подобраны под цены каталога, стоит сверить |
| Секция «Отзывы» | Три цитаты «Демо-отзыв» | Тексты придуманы |
| Секция «Как заказать» | Сроки (за 5–7 дней, за 3–4 дня) | Написаны по здравому смыслу |
| Секция «Вопросы» | Ответы про сроки, доставку, начинки | То же |
| Карточки каталога | Фото тортов | Сейчас цветные выкраски с силуэтом |

## Как добавить фото тортов

Положить файл в `images/` и дописать `data-photo` в блок `.swatch__chip`:

```html
<div class="swatch__chip" data-photo="images/bento-standart.jpg"><svg><use href="#cake-bento"/></svg></div>
```

Скрипт подставит фото фоном и спрячет силуэт. Пропорция кадра — 4:3.

## Дизайн

- **Идея.** Каталог как веер кремовых выкрасок: каждая позиция — цветовой образец
  с технической спецификацией (вес, порции, цена) моноширинным шрифтом. Форма заявки
  продолжает ту же логику: пронумерованные шаги и счётчик заполненных полей.
- **Шрифты.** Prata (заголовки), Onest (текст), JetBrains Mono (спецификации и подписи).
- **Цвета.** Молочный `#F2F4EF`, какао `#221F1B`, фисташка `#AFC3A0`, акцент — ягодный `#A32F4E`.
- Адаптив от 375 px, поддержка `prefers-reduced-motion`, видимый фокус на клавиатуре,
  поля формы связаны с подписями, ошибки объявляются через `role="alert"`.
